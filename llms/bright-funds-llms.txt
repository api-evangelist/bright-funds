# Bright Funds

> Bright Funds (now part of Submittable) is a workplace-giving, corporate grants, and employee volunteering platform used by employers to run donation, matching-gift, and volunteering programs for their employees, routing funds to vetted nonprofits. The platform exposes a live OpenID Connect / OAuth 2.0 authorization server at www.brightfunds.org for single sign-on and API integrations, though it publishes no standalone developer portal or OpenAPI specification.

## Identity & Auth
- OpenID Connect Discovery: https://www.brightfunds.org/.well-known/openid-configuration
- OAuth 2.0 Authorization Server Metadata (RFC 8414): https://www.brightfunds.org/.well-known/oauth-authorization-server
- Authorization endpoint: https://www.brightfunds.org/oauth/authorize
- Token endpoint: https://www.brightfunds.org/oauth/token
- UserInfo endpoint: https://www.brightfunds.org/oauth/userinfo
- JWKS: https://www.brightfunds.org/oauth/discovery/keys
- Scopes: openid, profile, email, name, offline_access, write, update
- Grants: authorization_code, client_credentials, implicit_oidc, refresh_token
